# CORE-07 — Журнал изменений

- Добавлены уникальный UUID idempotencyKey и requestFingerprint
  для защиты повторных созданий заказа по одному КП.
- Добавлены PurchaseOrder.version и PurchaseOrderRevision (append-only).
- Новый PATCH редактирования неоплаченного заказа по expectedVersion.
- При редактировании WAITING_PAYMENT статус оплаты сбрасывается в ORDERED.
- Отмена и переходы статусов фиксируют версии и снимки до/после.
- Добавлен GET allocation с требуемым/зарезервированным/
  заказанным/отменённым/свободным количеством и разрезом по поставщикам.
- В карточке закупки видны остатки и ограничения статусов,
  можно изменить заказ до оплаты.
- Добавлены E2E на параллельное резервирование, повторы,
  редактирование, отмену, историю и RBAC.
- SQL-миграция без удаления старых данных.
- Итоговые lint/build/E2E и ревью подтверждаются CI и вторым
  участником перед окончательным закрытием Issue #28.
