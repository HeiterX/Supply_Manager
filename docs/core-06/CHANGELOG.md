# CORE-06 — Журнал изменений (23.11.2026)

- Введён `SupplierDirectoryStatus` и реквизиты, категории, ответственный,
  уникальная нормализация и журнал `SupplierChange`.
- Реализованы API создания, поиска и редактирования поставщиков и история
  связанных КП и заказов.
- Добавлены `SupplierOffer.currency`, `validUntil`, `paymentTerms`,
  `deliveryTerms`, `version`, `decisionReason`, `decidedAt`.
- Добавлены append-only `SupplierOfferRevision` и `SupplierOfferDocument`.
- Сервер проверяет тип и размер файла, принадлежность КП закупке, JWT/RBAC,
  наличие версии. Файлы хранятся вне public.
- Редактирование КП не изменяет общую карточку поставщика, старые версии
  сохраняются; сделки по КП блокируют изменение.
- Добавлен ручной выбор КП с причиной и ограничение заказа по выбранному КП.
- Отрицательные сценарии вошли в E2E.
- UI: справочник, поиск поставщика в КП, таблица сравнения, версии,
  документы, причины решения, договорные условия, явные неизвестные значения.

Дальнейшие условия завершения: успешные CI, ручной smoke-test и code review.
