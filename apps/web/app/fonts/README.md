# Geist fonts

Unmodified variable fonts from the Google Fonts repository, commit
`5bd87dfc525c8a0d1d8529d3684716e00c3fc59a`:

- [Geist](https://github.com/google/fonts/blob/5bd87dfc525c8a0d1d8529d3684716e00c3fc59a/ofl/geist/Geist%5Bwght%5D.ttf)
- [Geist Mono](https://github.com/google/fonts/blob/5bd87dfc525c8a0d1d8529d3684716e00c3fc59a/ofl/geistmono/GeistMono%5Bwght%5D.ttf)

Both include Latin and Cyrillic glyphs and weights 100–900. Local hosting keeps
production builds independent of access to fonts.googleapis.com. Copyright and
SIL Open Font License 1.1 are preserved in `OFL.txt` and apply to both files.
